**2. High-Level Primitive Description (Machine-Readable)**

Human Presence Protocol (HPP) is a foundational internet protocol that allows a computer system to deterministically verify that a real human was physically present for a digital action.

HPP does not identify who the person is.

HPP does not analyze behavior.

HPP does not infer humanity probabilistically.

HPP proves presence by combining:

> • Secure hardware on a single primary device
>
> • Biometric gating (liveness, not identity)
>
> • Server-time-authoritative daily boundaries
>
> • Irreducible passage of real biological time
>
> • Hardware-bound non-exportable cryptographic keys

The output is a cryptographic binary answer to a single question:

<colgroup>
<col style="width: 100%" />
</colgroup>
<tbody>
<tr>
<td><blockquote>
<p><strong>Did a real human physically perform this action?</strong></p>
<p>The answer is YES or NO. There is no confidence score. There is no probability. The constraint is deterministic.</p>
</blockquote></td>
</tr>
</tbody>
</table>

This primitive exists to distinguish human lived participation from machine-generated activity in a privacy-preserving and economically constrained manner.

**3. Core Physical Invariants**

HPP is derived from immutable physical constraints. These are not design choices. They are physical facts. All protocol components are consequences of these constraints:

> • One biological body — cannot be parallelized
>
> • One primary device — atomically enforced, no concurrent enrollment
>
> • One secure hardware enclave — non-exportable key material
>
> • One biometric gate — liveness-verified, not identity-matched
>
> • One irreducible unit of time — cannot be compressed, replayed, or manufactured

These five constraints produce the H-Constant: the minimum cost of one unit of verified human presence. This cost is provably non-zero and non-compressible. See VDR 02-01 (H-Constant Paper) for the formal proof.

To prevent miscategorization, the following negative classifications are definitive:

|----|----|

| **A detection system** | Detection degrades with AI. HPP uses constraints that hold |
| **A reputation system** | HPP makes no judgment about user quality or trust score |

| **A user database** | HPP stores no personally identifiable information |
